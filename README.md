# Régie de vidéodébriefing — démonstration

Démonstration en ligne de la régie du kit mobile de vidéodébriefing de LSD (Life Support Distribution), pour la simulation en santé.

Toutes les données sont simulées : images d'illustration, moniteur patient dessiné en direct, aucun flux réel. Ce dépôt ne contient que la version compilée de la démonstration.

Contact : contact@lifesupportdistribution.fr
